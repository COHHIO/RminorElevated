# Living Situation Reference Number Translation \`r lifecycle::badge("deprecated")\`

Deprecated in favor of \`hud_translations\`. Return a human-readable
living situation character vector provided with an integer reference
number

## Usage

``` r
living_situation(ReferenceNo)
```

## Arguments

- ReferenceNo:

  `(integer)` Reference number for living situation type

## Value

`(character)` Human-readable living situation type
